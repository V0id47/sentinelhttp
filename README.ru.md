# SentinelHTTP

[English](README.md) · [Español](README.es.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md)

SentinelHTTP — локальный инструмент для ограниченной проверки конфигурации
HTTP/HTTPS и проект для профессионального портфолио по кибербезопасности.
По умолчанию он получает один ответ, связывает осторожные выводы с
доказательствами, рассчитывает оценку конфигурации с указанием полноты
проверки, сравнивает совместимые отчёты и показывает их в локальной панели.
Инструмент не доказывает возможность эксплуатации или безопасность всего сайта.

Проверяйте только свои системы или системы, на проверку которых у вас есть разрешение.

## Быстрый запуск

Нужен Go 1.26+ (в CI используется 1.27.1). Встроенная панель работает без
Node.js; для её пересборки нужны Node.js 24 и npm. См. [установку](docs/install.md).

```console
go run ./cmd/sentinelhttp version
go run ./cmd/sentinelhttp scan http://127.0.0.1:8080/ --allow-private --format json --output report.json --lang ru
go run ./cmd/sentinelhttp serve report.json
```

Пример предполагает локальный HTTP-сервис на порту 8080. Панель слушает
случайный порт `127.0.0.1`; `--no-open` отключает открытие браузера.
Существующие файлы отчётов не перезаписываются.

Для HTTPS в Windows, macOS и iOS требуется актуальный PEM-набор корневых
сертификатов через `--ca-file roots.pem`. Это позволяет Go проверять
сертификаты без получения издателей через сеть вне разрешённой границы.
Переданный набор заменяет системные корни для этой проверки; проверка TLS
никогда не отключается.

```console
go run ./cmd/sentinelhttp scan https://your-authorized-host.example/ --ca-file roots.pem --format json --output before.json --lang ru
go run ./cmd/sentinelhttp diff before.json after.json --format terminal --lang ru
go run ./cmd/sentinelhttp scan http://127.0.0.1:8080/ --allow-private --trace-redirects --probe-cors --max-redirects 3 --max-requests 7
```

Без дополнительных флагов выполняется один GET. Последняя команда явно
разрешает локальный лабораторный сценарий: до четырёх GET при переходах и три
образца CORS без учётных данных. Каждый запрос проходит проверку области
доступа и фактического TCP-адреса. Частные и loopback-адреса запрещены по
умолчанию; `--allow-private` разрешает их и ограничивает переходы исходным
хостом. Переход HTTPS→HTTP блокируется. Нет обхода сайта, входа в аккаунт,
отправки cookie или авторизованных проб.

## Отчёты и конфиденциальность

Версионированный JSON содержит ограниченные данные HTTP, TLS, защитных
заголовков, cookie, CSP, CORS и переходов. Для каждого вывода указаны
наблюдение, интерпретация, уверенность и ограничения. Оценка относится только
к одному основному ответу и показывает доступность данных по областям.
Отсутствие находок не означает безопасность приложения.

Пути, строки запроса, тела ответов, значения cookie и исходные значения
`Location` не сохраняются. Домен, данные сертификата и имена cookie всё ещё
могут быть чувствительными; защищайте файлы отчётов. `diff` автоматически
сравнивает только совместимые проверки корневого URL без параметров одного
источника и помечает неопределённость как `unknown`. Панель принимает
проверенные локальные отчёты, но не подтверждает их происхождение.

## Архитектура и проверка

Пакет `network` единолично открывает исходящие соединения сканирования;
`dashboard` открывает только входящий loopback-порт. Анализаторы, движок
находок, оценка, отчёт и diff обрабатывают уже собранные данные без сетевых
запросов. React/TypeScript-панель встроена в Go-бинарник без CDN.
[Архитектура](docs/architecture.md) · [самооценка](docs/architecture-self-review.md) ·
[описание проекта](docs/portfolio.md).

```console
go test ./...
go vet ./...
npm ci --prefix frontend
npm run build --prefix frontend
```

Тесты используют искусственные DNS/соединения и локальные HTTP/TLS-серверы,
а не общедоступные цели. CI запускает детектор гонок Go в Linux и проверки
зависимостей; на локальной Windows-машине нет C-компилятора для `go test -race`.
Интерфейс поддерживает английский, испанский, русский и упрощённый китайский;
`--lang` не изменяет JSON. [CLI](docs/cli.md) · [Разработка](docs/development.md).
